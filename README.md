# 던전 디펜스 (Dungeon Defense)

모바일/PC/태블릿에서 플레이 가능한 웨이브 디펜스 게임입니다. 순수 HTML/CSS/JavaScript로 제작되었으며 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행 방법

`index.html`을 정적 서버로 서빙하면 됩니다 (파일을 더블클릭해서 바로 열어도 대부분 동작하지만, 로컬 서버 사용을 권장합니다).

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## GitHub Pages로 배포하기

1. 이 폴더를 GitHub 저장소에 푸시합니다.
2. 저장소 Settings → Pages → Source를 `main` 브랜치의 `/ (root)`로 설정합니다.
3. 몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 에서 게임을 즐길 수 있습니다.

## 주요 기능

- 던전(10종, 난이도 증가) / 보스(5종) / 챌린지(지옥 난이도) 모드
- 웨이브 기반 디펜스: 4레인 기지 이동, 조이스틱 조준 사격, 특수무기, 탄약 시스템
- 보스전: 자유 이동 보스, 원거리 공격 텔레그래프 회피
- 장비 시스템: 칼/갑옷/무기, 레벨업, 10레벨 이후 벌집형 각성
- 상점: 개성있는 상인 4종 + 가챠(천장 시스템 포함)
- 모든 진행 상황은 브라우저 `localStorage`에 저장됩니다.
